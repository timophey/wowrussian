# Разработка алгоритма конвертации PDF-словаря

## Исходная задача

Необходимо преобразовать PDF-словарь Виноградова (3188 страниц) в структурированные форматы JSON и Excel. Слова начинаются со страницы 9.

## Источники словарей

Официальный источник нормативных словарей: <https://ruslang.ru/normativnyje_slovari>

- **Орфографический словарь Виноградова** - "Орфографический словарь русского языка"
- **Орфоэпический словарь** - "Орфоэпический словарь русского языка как государственного языка Российской Федерации"
- **Толковый словарь** - "Толковый словарь русского языка" (возможно, не из этого источника)

Все словари являются нормативными изданиями Российской академии наук.

## Этап 1: Анализ структуры PDF

### Проблема
PDF - это не структурированный текст. Нужно понять, как представлены словарные статьи.

### Решение
Использовали `pdfplumber` для извлечения символов с метаданными:
- Координаты (x0, top)
- Шрифт (fontname)
- Текст символа

Создали скрипт [`vinogradov_analyze_page.py`](vinogradov_analyze_page.py), который:
1. Группирует символы по строкам (координата `top` с округлением до 0.1)
2. Для каждой строки выводит:
   - Номер строки
   - Координату top
   - Количество жирных сегментов
   - Наличие запятой
   - Пример текста

### Результаты анализа страницы 9

Обнаружили закономерности:
1. Словарные статьи имеют формат: `СЛОВО, описание форм...`
2. **Слово** выделено **жирным** шрифтом `TimesNewRomanPS-BoldMT`
3. После слова всегда следует запятая
4. В конце строки могут быть символы ударения (акут `\u0301`), которые не являются отдельными строками
5. Некоторые строки состоят только из символов ударения - их нужно игнорировать

Пример:
```
а, нескл., с. (название буквы)
```
- Жирное: "а"
- Запятая: есть
- Формы: "нескл., с. (название буквы)"

## Этап 2: Простой прототип

Создали [`test_simple.py`](test_simple.py) в `tools.bac/`, который:

## Этап 3: Разработка основного алгоритма

### Ключевые решения

1. **Использовать жирный шрифт как маркер слова**
   - Только жирный текст перед первой запятой - это слово
   - Это надежнее, чем проверка на заглавную букву

2. **Обработка ударений**
   - Ударения представлены отдельными символами акута
   - Они могут стоять после слова или на отдельной строке
   - Функция `remove_accents()` удаляет `\u0301` и `́`
   - Функция `is_only_accents()` пропускает строки, состоящие только из ударений

3. **Извлечение форм**
   - Все, что после первого жирного сегмента (слова) - это forms
   - Сохраняем как одну строку, чтобы не терять вложенные запятые и скобки
   - Убираем начальную запятую если есть

4. **Группировка по строкам**
   - Используем координату `top` с округлением до 0.1
   - Сортируем строки сверху вниз

### Алгоритм (псевдокод)

```
Для каждой страницы (начиная с 9):
    Получить все символы страницы
    Сгруппировать символы по top (с округлением)
    Отсортировать группы по top (сверху вниз)
    
    Для каждой группы (строки):
        Собрать текст строки
        Если строка пустая или только ударения -> пропустить
        Если нет запятой -> пропустить
        
        Найти все жирные сегменты (последовательные символы с TimesNewRomanPS-BoldMT)
        Если нет жирных сегментов -> пропустить
        
        word_raw = первый жирный сегмент
        word_clean = удалить ударения из word_raw
        
        after_word = все после word_raw в строке
        Если after_word начинается с запятой -> убрать
        
        forms = [after_word] если not empty
        
        Сохранить запись: {word, forms, full_line, page_num}
```

## Этап 4: Оптимизация для больших объемов

### Проблема
При обработке 3180 страниц одновременно:
- Слишком большой список `pages_list = pdf.pages[start_idx:end_idx]` загружает все страницы в память
- Процесс умирает с SIGKILL (нехватка памяти)

### Решение
1. **Ленивая загрузка страниц**: вместо создания списка всех страниц, используем `range()` и обращаемся к `pdf.pages[page_idx]` по индексу
2. **Освобождение памяти**: `del page` после обработки + `gc.collect()` каждые 100 страниц
3. **Прогресс-бар**: `tqdm` для визуализации прогресса

## Ключевые инсайты для других словарей

### 1. Маркер словаря
- **Что искать**: Уникальный шрифт для лемм (часто жирный или особый)
- **Как определить**: Анализ нескольких страниц через `analyze_page.py`

### 2. Структура статьи
- **Разделитель**: Обычно запятая, точка с запятой, тире
- **Порядок**: Слово → разделитель → описание
- **Множественные формы**: Могут быть в скобках или через запятые

### 3. Проблемные случаи
- **Строки с ударениями**: Могут быть отдельными строками, нужно фильтровать
- **Переносы слов**: В PDF могут быть разрывы строк, нужно проверять
- **Спецсимволы**: Тире, кавычки, скобки - сохранять как есть

### 4. Производительность
- **Не загружать все страницы сразу** - используйте ленивую загрузку по индексу
- **Очищать память** после каждой страницы
- **Прогресс-бар** для мониторинга
- **Сохранение промежуточных результатов** (опционально) для возобновления после сбоя

### 5. Валидация
- Проверить первую и последнюю страницу
- Убедиться, что количество записей соответствует ожиданиям (~25-30 на страницу)
- Проверить несколько случайных записей вручную

```python
def extract_dictionary(pdf_path, start_page, bold_fontname):
    entries = []
    with pdfplumber.open(pdf_path) as pdf:
        for page_idx in tqdm(range(start_page-1, len(pdf.pages))):
            page = pdf.pages[page_idx]
            chars = page.chars
            
            # Группировка по строкам
            lines_dict = {}
            for char in chars:
                top_key = round(char['top'], 1)
                lines_dict.setdefault(top_key, []).append(char)
            
            for top in sorted(lines_dict.keys()):
                line_chars = sorted(lines_dict[top], key=lambda c: c['x0'])
                line_text = ''.join(c['text'] for c in line_chars).strip()
                
                # Фильтры
                if not line_text or is_only_noise(line_text):
                    continue
                
                # Найти целевой сегмент (жирный/особый шрифт)
                segments = extract_bold_segments(line_chars, bold_fontname)
                if not segments:
                    continue
                
                word = clean_word(segments[0])
                forms = extract_forms(line_text, word)
                
                entries.append({
                    'word': word,
                    'forms': forms,
                    'full_line': line_text,
                    'page_num': page_idx + 1
                })
                
                del page  # освободить память
    return entries
```

## Заключение

Алгоритм основан на:
1. **Анализе шрифтов** - жирный шрифт как маркер слова
2. **Структурных эвристиках** - запятая как разделитель
3. **Фильтрации шума** - ударения, пустые строки
4. **Оптимизации памяти** - ленивая загрузка, очистка

Этот подход применим к большинству типографских словарей PDF.
