# Конвертер орфоэпического словаря русского языка

Инструмент для преобразования PDF-словаря "Орфоэпический словарь русского языка как государственного языка Российской Федерации" в структурированные форматы JSON и Excel.

## Источник

Официальный источник словаря: <https://ruslang.ru/normativnyje_slovari>

Нормативные словари Российской академии наук.

## Файлы

- `orfoepicheskij_convert.py` - основной скрипт конвертации
- `orfoepicheskij_analyze_page.py` - инструмент для анализа структуры PDF
- `orfoepicheskij_slovar.pdf` - исходный PDF-файл словаря (13 MB, 1471 страница)
- `orfoepicheskij_dictionary.json` - полные данные в формате JSON (22,196 записей)
- `orfoepicheskij_dictionary.xlsx` - данные в формате Excel

## Результаты конвертации

- **JSON** - полные данные с полной информацией
- **Excel** - данные с колонками:
  - **Слово** - лемма (основная форма слова)
  - **Формы** - строка с описанием форм и правил
  - **Количество форм** - число (всегда 1, так как формы хранятся как единая строка)
  - **Страница** - номер страницы в исходном PDF

## Установка и запуск

### Требования
- Python 3.8+
- Виртуальное окружение уже создано в `tools/venv/`

### Запуск тестового режима (первые 10 страниц)

```bash
cd tools
source venv/bin/activate
python orfoepicheskij_convert.py
```

По умолчанию скрипт запускается в тестовом режиме (обрабатывает 10 страниц, начиная со страницы 13).

### Запуск полной конвертации

Отредактируйте `orfoepicheskij_convert.py`, изменив параметр `test_mode`:

```python
test_mode = False  # Полная конвертация
max_pages = None   # Обрабатываем все страницы
```

Затем запустите:

```bash
cd tools
source venv/bin/activate
python orfoepicheskij_convert.py
```

## Алгоритм извлечения

1. Обработка начинается со страницы 13 (основной словарь)
2. Текст группируется по строкам (координата `top`)
3. Для каждой строки:
   - Пропускаются строки без запятых
   - Пропускаются строки, состоящие только из символов ударения
   - Находятся жирные сегменты (шрифт `TimesNewRomanPS-BoldMT`)
   - Первый жирный сегмент считается словом (леммой)
   - Все, что после слова, сохраняется как `forms`
   - Ударения (акут) удаляются из слова
4. Результат сохраняется в JSON и Excel

## Статистика

- Всего страниц в PDF: 1471
- Страниц для обработки: 1459 (с 13 по 1471)
- Извлечено записей: 22,196
- Время обработки: ~7-10 минут

## Примечания

- Формы хранятся как единая строка, чтобы сохранить вложенные запятые, скобки и специальные символы (□, \\ и др.)
- В текущей реализации `Количество форм` всегда равно 1, так как `forms` - это список из одной строки
- Для разделения форм на отдельные элементы потребуется дополнительная обработка

## Структура JSON

```json
{
  "word": "АБАК",
  "forms": ["абака, мн. абаки, абакам □ Приспособление для вычислений; термин в"],
  "full_line": "АБАК, абака, мн. абаки, абакам □ Приспособление для вычислений; термин в",
  "page_num": 13
}
```

## Troubleshooting

### Ошибка "No module named 'pdfplumber'"
Убедитесь, что виртуальное окружение активировано:
```bash
cd tools
source venv/bin/activate
```

### Процесс завершается с ошибкой памяти
Уменьшите количество обрабатываемых страниц, установив `max_pages` в параметрах.

### Медленная обработка
Обработка 1459 страниц может занять 7-15 минут. Это нормально для PDF такого объема.
