# Конвертер орфографического словаря Виноградова

Инструмент для преобразования PDF-словаря "Орфографический словарь русского языка" (Виноградов) в структурированные форматы JSON и Excel.

## Источник

Официальный источник словаря: <https://ruslang.ru/normativnyje_slovari>

Нормативные словари Российской академии наук.

## Файлы

- `vinogradov_convert.py` - основной скрипт конвертации
- `vinogradov_analyze_page.py` - инструмент для анализа структуры PDF
- `orfograficheskij_slovar.pdf` - исходный PDF-файл словаря (31 MB, 3188 страниц)
- `venv/` - виртуальное окружение Python

## Результаты конвертации

- `vinogradov_dictionary.json` - полные данные в формате JSON (82,557 записей)
- `vinogradov_dictionary.xlsx` - данные в формате Excel с колонками:
  - **Слово** - лемма (основная форма слова)
  - **Формы** - строку с описанием форм и правил
  - **Количество форм** - число (всегда 1, так как формы хранятся как единая строка)
  - **Страница** - номер страницы в исходном PDF

## Установка и запуск

### Требования
- Python 3.8+
- Виртуальное окружение уже создано в `tools/venv/`

### Запуск тестового режима (первые 10 страниц)

```bash
cd tools
source venv/bin/activate
python vinogradov_convert.py
```

По умолчанию скрипт запускается в тестовом режиме (обрабатывает 10 страниц).

### Запуск полной конвертации

Отредактируйте `vinogradov_convert.py`, изменив параметр `test_mode`:

```python
test_mode = False  # Полная конвертация
max_pages = None   # Обрабатываем все страницы
```

Затем запустите:

```bash
cd tools
source venv/bin/activate
python vinogradov_convert.py
```

## Алгоритм извлечения

1. Обработка начинается со страницы 9 (основной словарь)
2. Текст группируется по строкам (координата `top`)
3. Для каждой строки:
   - Пропускаются строки без запятых
   - Пропускаются строки, состоящие только из символов ударения
   - Находятся жирные сегменты (шрифт `TimesNewRomanPS-BoldMT`)
   - Первый жирный сегмент считается словом (леммой)
   - Все, что после слова, сохраняется как `forms`
   - Ударения (акут) удаляются из слова
4. Результат сохраняется в JSON и Excel

## Статистика

- Всего страниц в PDF: 3188
- Страниц для обработки: 3180 (с 9 по 3188)
- Извлечено записей: 82,557
- Время обработки: ~15-20 минут (зависит от системы)

## Примечания

- Формы хранятся как единая строка, чтобы сохранить вложенные запятые и скобки
- В текущей реализации `Количество форм` всегда равно 1, так как `forms` - это список из одной строки
- Для разделения форм на отдельные элементы потребуется дополнительная обработка

## Структура JSON

```json
{
  "word": "а",
  "forms": ["нескл., с. (название буквы)"],
  "full_line": "а, нескл., с. (название буквы)",
  "page_num": 9
}
```

## Troubleshooting

### Ошибка "No module named 'pdfplumber'"
Убедитесь, что виртуальное окружение активировано:
```bash
cd tools
source venv/bin/activate
```

### Процесс завершается с ошибкой памяти
Уменьшите количество обрабатываемых страниц, установив `max_pages` в параметрах.

### Медленная обработка
Обработка 3180 страниц может занять 15-30 минут. Это нормально для PDF такого объема.
